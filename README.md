
A simple browser-based calculator for basic arithmetic. The interface is built with HTML and CSS, and calculator interactions are handled with JavaScript.

## Features

- Addition, subtraction, multiplication, and division
- Modulo (`%`) calculations
- Decimal number input
- Clear (`AC`) and delete (`DEL`) controls
- Displays the current expression as buttons are pressed

## Technologies

- HTML5
- CSS3
- JavaScript

## Run locally

Clone the repository:

```bash
git clone https://github.com/Shubhankar971/calculator.git
cd calculator
```

Open `index.html` in a web browser. No dependency installation or build step is required.
